# Group Tabs Sidebar

Το **Group Tabs Sidebar** είναι μια επέκταση για τον Firefox (Manifest V3) που οργανώνει αυτόματα τις ανοιχτές καρτέλες σου ανά domain σε μια κομψή πλαϊνή στήλη (sidebar) με εφέ γυαλιού (3D glassmorphism). Αντί για μια ατελείωτη λίστα από καρτέλες, βλέπεις κάθε domain ως μια ξεχωριστή ομάδα, με το εικονίδιό του, το όνομά του και τον αριθμό των καρτελών που περιέχει.

## ✨ Βασικές Λειτουργίες
- **Αυτόματη Ομαδοποίηση**: Μόλις ανοίξεις μια νέα καρτέλα, αυτή τοποθετείται αυτόματα στην ομάδα του αντίστοιχου domain.
- **Πολλαπλά Παράθυρα**: Κάθε παράθυρο του Firefox εμφανίζεται ως ξεχωριστή ενότητα με τον δικό του τίτλο και χρώμα.
- **Drag & Drop (Trees)**: Σύρε ένα domain πάνω σε άλλο για να δημιουργήσεις ένα "Tree". Μπορείς να αναδιατάξεις, να κάνεις unmerge ή να κλείσεις ολόκληρο το Tree.
- **3D Popups**: Κάνοντας κλικ σε ένα domain, ανοίγει ένα γυάλινο popup με όλες τις καρτέλες του, επιτρέποντάς σου να μεταβείς, να κλείσεις ή να αποκρύψεις καρτέλες.
- **Απόκρυψη Καρτελών**: Κρύψε καρτέλες χωρίς να τις κλείσεις και επανέφερέ τες όποτε θέλεις.
- **Προσαρμογή & Zoom**: Υποστήριξη zoom με κουμπιά ή `Ctrl + Scroll`, με αυτόματη αποθήκευση της επιλογής σου.
- **Σκούρο Θέμα (Dark Mode)**: Πλήρης υποστήριξη σκούρου θέματος για άνετη χρήση.

## 🔒 Απόρρητο & Ασφάλεια
- **100% Τοπική Λειτουργία**: Δεν πραγματοποιείται καμία εξωτερική σύνδεση.
- **Καμία Συλλογή Δεδομένων**: Δεν συλλέγονται προσωπικά δεδομένα.
- **Ελάχιστα Δικαιώματα**: Χρησιμοποιεί μόνο τα απαραίτητα δικαιώματα (`tabs`, `storage`, `tabHide`, `alarms`, `notifications`).

## 📥 Εγκατάσταση
Μπορείς να εγκαταστήσεις την τελευταία έκδοση απευθείας από το κατάστημα προσθέτων της Mozilla:
👉 [Group Tabs Sidebar στο Firefox Add-ons](https://addons.mozilla.org/el/firefox/addon/group-tabs-sidebar/)

### 🛠️ Εγκατάσταση για Ανάπτυξη (Development)
Αν θέλεις να φορτώσεις την επέκταση τοπικά για δοκιμή ή ανάπτυξη:
1. Κατέβασε ή κάνε clone αυτό το repository.
2. Άνοιξε τον Firefox και πήγαινε στη διεύθυνση `about:debugging`.
3. Πάτα **"This Firefox"** και μετά **"Load Temporary Add-on..."**.
4. Επίλεξε το αρχείο `manifest.json` από τον φάκελο του project.
